# 招生咨询对话示范评审标准

本标准用于编写和审核 `references/dialogues/` 中的多轮示范。示范的价值在于展示决策过程，而不是堆叠背景知识或追求固定措辞。

## 必须满足

每段示范都应：

- 明确示范面向的是考生本人、家长还是招生志愿者，并据此决定输出是“直接回答”还是“心理判断 + 话术指导”；
- 明确用户的真实目标、身份阶段和所问实体；
- 面向考生时，体现“从字面诉求到决策意图再到心理内核”的下钻过程，而不是只答字面问题，也不是凭空套情绪标签；
- 心理判断有对话依据：能从考生的措辞、未问的内容、信息来源或时间节点中说出判断从何而来；
- 情绪被当作待验证假设：在直接定性前用一句校准性回问向考生确认；
- 面向志愿者时，同时给出“考生心理判断”和“可直接使用的话术”，并展示接情绪 → 下钻澄清 → 分层回应 → 留一步的结构；
- 志愿者话术能应对后续追问，且标注需替换的字段与志愿者的边界（何时应引导考生查官方而非自行下结论）；
- 只在缺失信息会改变答案时追问；
- 正确区分稳定事实、当前轮次事实和历史参考；
- 对动态事实要求回查当前官方原页；
- 不把通班、智班、元培、智能学院和人工智能研究院混为一谈；
- 在证据不足时明确未知，不用往年规则外推；
- 给出与用户当前目标相匹配的下一步；
- 语言自然，可以作为真实咨询的参考，而不是像规则清单。

## 建议的示范元信息

在每段对话前简要注明：

```text
场景：
服务对象：考生本人 / 家长 / 招生志愿者
主要诉求：
考生深层需求：
情绪底色：
对话线索：从哪些措辞/未问内容/来源读出上述判断
需要展示的能力：
关键事实风险：
```

随后给出至少两轮用户与助手交流，使读者能够看到助手如何根据新增信息调整判断。

## 不应合入的情况

- 助手一开始就询问大量与当前判断无关的个人信息；
- 没有回答可立即回答的部分，只让用户自行查看官网；
- 使用“稳进”“大概率录取”等无依据承诺；
- 把示范写成单轮百科答案，未体现需求校准或行动引导；
- 引用动态数字、日期、联系方式却没有适用年度和官方依据；
- 为了展示话术而虚构用户身份、成绩或官方文件；
- 只用情绪标签代替分析，或心理判断凭空而来、脱离考生的措辞与语境（如只写“考生焦虑”却不说明从哪句读出，或凭空猜测动机）；
- 面向志愿者的示范只有“台词”而没有对考生心理的判断，或未说明字段替换与后续追问的接续方式；
- 给志愿者的回答照搬“考生→官方”模板，未区分服务对象；
- 话术只接情绪不给事实，或只倒信息不接情绪，未做分层回应；
- 话术越过志愿者边界，替招生单位下录取结论或承诺资格。

## 合入前检查

作者先按本标准自检；另一位成员再从事实准确性、对话自然度、可执行性，以及“考生心理与深层需求判断是否有对话依据、话术是否可落地”四个角度复核。事实或规则变化时，优先更新或移除过时示范，不能让示范反过来成为未经核验的事实来源。
